# Hopety — Landing Page

Strona landingowa aplikacji mobilnej **Hopety** dla właścicieli psów i kotów.

## Tech Stack

- **Next.js 14+** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Motion** (animacje)
- **Nodemailer** (formularz waitlisty via SMTP)

## Funkcje

- Sekcja hero z mockupem telefonu
- 5 kart z funkcjami aplikacji
- Galeria screenshotów
- Formularz zapisów na waitlistę
- Modalne okna prawne (regulamin, polityka prywatności)
